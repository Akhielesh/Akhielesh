- `https://akhielesh.github.io/Akhielesh/`

- `https://akhielesh.com`

Issues stay enabled here because the public remarks/guestbook on the portfolio is powered by GitHub Issues.

## Adminak

[`adminak/`](adminak/) contains **Adminak**, a self-hosted personal intelligence console. It scans connected mailboxes (Gmail or IMAP) for subscriptions, bills, money, career, travel, orders and security events. It shows them on a mobile-first dashboard and emails alerts, daily briefs and reports to a personal address. Setup and deployment are covered in [`adminak/README.md`](adminak/README.md).

GitHub Pages only publishes the redirect files (`index.html`, `404.html`, `.nojekyll`). The app is deployed separately, for example with Docker or on Railway.
